# Prism Insight · 退款异常分析工作台

将真实订单数据转为可审核的分析报告：导入不可变数据快照 → 模型生成受约束计划 → 参数化聚合查询 → 程序计算 → 双人审核 → 站内发布。

**交付状态：上线候选实现，尚待后端主机与真实模型环境验收。GitHub Pages 仅是客户端，不能代替后端部署。**

## 当前实现

- 真实 UTF-8 CSV 导入，逐行校验、订单号去重、整批原子提交，不自动生成业务订单。
- 用户明确选择基准期与当前期；模型只能选择分组维度和存在的过滤值，不能执行任意 SQL、改写日期或编造数值。
- LangGraph 组织计划、查询、分析、报告节点；PostgreSQL 持久任务队列负责故障恢复。恢复粒度是整个只读分析作业，不冒称节点级 checkpoint 恢复。
- 数据集快照与任务绑定、幂等请求键、租约续期与 fencing；模型故障明确失败，无规则模拟报告兜底。
- 分析师/审核人/管理员分工，报告 hash 绑定审批，任何角色都不能审批自己发起的任务。
- 审核通过后将报告实际发布到发起人的站内通知；事务与唯一约束确保不重复发布。不假称已经发送邮件、企业微信或钉钉。
- 所有可见数据受租户/任务归属限制，审计与账号停用即时生效。

## 范围和历史研究

当前产品不是“自由自治的四Agent系统”：用受约束工作流处理明确问题，优先保证数字、审批和发布可靠。历史 app/workflow.py、app/tools.py、app/mcp_server.py 是 SQLite/合成数据基线研究，不作为生产入口；生产部署只启动 app.main:create_app 与 app.worker。没有把旧研究中的 MCP、A2A、SQLite checkpoint 写成当前线上能力。

面试手册独立交付，不放在产品导航。阶段一成功率和压测数字不能代表当前实际模型与生产部署表现。
